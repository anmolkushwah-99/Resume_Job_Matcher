How Matching Works

Academic methodology and explainability guide for the AI-Based Resume Screening System.

End-to-End Processing Pipeline

  1. Resume Text Extraction: Uploaded PDF resumes are parsed using pypdf with privacy-safe storage.
  2. NLP Entity & Skill Extraction: spaCy and NLTK tokenize text, detect sections (Education, Experience, Skills), and extract candidate competencies.
  3. TF-IDF Feature Representation: Resume text and job description are transformed into a combined TF-IDF feature space (5,000 max features, unigrams & bigrams).
  4. Supervised Linear SVM Inference: The frozen LinearSVC (C=1.0, balanced class weight) computes the signed hyperplane distance.
  5. Ranking & Classification: Jobs are classified as MATCH if decision_score ≥ 0.0 and ranked strictly by decision_score DESC with tie-breaker job_id ASC.
  6. Skill Gap Explanation: Candidate skills and job required skills are intersected to compute matched skills, missing skills, and auxiliary skill overlap ratio.

Critical Interpretation Guidelines

1. Decision Score is Not a Probability: LinearSVC produces a signed geometric distance from the separating hyperplane. A score of 1.4521 indicates strong positive separation, NOT 145% or 92% probability.

2. Skill Overlap is an Auxiliary Signal: Skill Overlap Ratio measures keyword intersection |Resume Skills ∩ Job Skills| / |Job Skills|. It provides human explainability and does not replace the SVM decision score.

3. Decision Support Only: This application is designed as an academic decision-support tool for recruiters and candidates. It does not automate final hiring decisions.
